# TaskFlow – To Do Manager

TaskFlow is a simple **daily task manager** built using **HTML, CSS, and JavaScript** to help users organize and track their daily tasks.

## 🔗 Live Demo

[TaskFlow – Live Demo](https://glittering-mousse-7e0e52.netlify.app/)

## Features

* ➕ Add new tasks anytime
* ✏️ Edit tasks
* 🗑️ Delete tasks
* ✅ Mark tasks as completed
* 🔍 Search tasks
* 🔖 Filter tasks by **All, Active, and Completed**
* 🌙 Light/Dark mode
* 📅 Automatically carries unfinished tasks to the next day
* 📊 Keeps track of tasks and their completion status
* 💾 Saves tasks using browser **Local Storage**
* 📱 Responsive design

## Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling & responsive design
* **JavaScript** – Functionality & task management
* **LocalStorage** – Persistent task data
